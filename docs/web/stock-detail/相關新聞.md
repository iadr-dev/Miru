# 個股 › 相關新聞 (news)

Parent: [../stock-detail.md](../stock-detail.md). Nested category sub-tabs (§6.3).

## Sub-tabs (segmented)
| Sub-tab | Content | Component | Endpoint |
|---------|---------|-----------|----------|
| **即時新聞** | fast RSS stream (鉅亨/經濟日報/TechNews), time-ordered, minimal curation — "what just broke" | `MarketNews` (realtime) | `get_stock_news?category=realtime` |
| **財經新聞** | curated financial coverage (FinMind history + Finnhub + GDELT), topic/sentiment-classified | `MarketNews` (finance) | `get_stock_news?category=finance` |
| **PTT 討論** | PTT Stock/Tech_Job buzz — post volume, 推文數, crowd sentiment, flagged **未經證實散戶意見** | (buzz card) | `get_social_buzz` |
| **名人事件** | 名人 (黃仁勳/馬斯克/巴菲特…) events touching this stock, avatar + linked news | `FigureEventsFeed` | `get_figure_events` |

All `public`, sentiment via NLP. Each item: 時間·來源·標題·情緒 chip.

## Visual design
Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Sub-tab bar =
segmented pill row, active `--accent` + shared-layout glide (§6.3).

- **News feed** (`MarketNews`) — `divide-y --border` list on `--surface`, newest first; each row:
  時間 (13px `--text-muted`, tabular) · 來源 chip · 標題 (16px/1.7) · **情緒 chip** (看多 `--up`-tint /
  看空 `--down`-tint / 中性 `--text-muted` — always with a text label, never color-alone). Row → source.
- **即時新聞** = denser, minimal chrome (fast RSS); **財經新聞** = curated, topic chip added.
- **PTT 討論** = buzz card: 推文數/post-volume mini-bar + crowd sentiment, with a **`--warn` "未經證實
  散戶意見" banner** pinned on the card. PTT Beauty/Gossiping never here.
- **名人事件** (`FigureEventsFeed`) — figure avatar (`FigureAvatar`, round) + linked event + affected
  stock/theme chips; non-analysis framed.
- States: loading = shimmer list rows; empty → 「近期無相關新聞」.

## Governance
PTT buzz is **flagged unverified retail opinion**, excluded from investment rationale (guardrail).
PTT Beauty/Gossiping (`get_trending_buzz`) is **never** here — mascot/whimsy only. News claims are
external → non-trading framing; no 明牌/目標價 restatement.
