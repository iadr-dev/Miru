# 個股 › 即時 (realtime) — Premium

Parent: [../stock-detail.md](../stock-detail.md). Sponsor tab — mosaics for Free.

## Content (`RealtimeTab`)
- **委買賣 best-5 ladder** — 五檔買/賣量價, live-flash on update.
- **逐筆 / 分K** — intraday tick + minute-K chart (`ChartWithDataSheet` candle, intraday TF).
- **當沖率** — day-trade % of volume.

## Endpoint
`get_realtime_snapshot`, `get_intraday_kbars` (+ MIS best-5). **Sponsor** (`price_intraday`).

## Visual design
Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Dark-first.

- **委買賣 best-5 ladder** — 5 買 rows / 5 賣 rows, `divide-y --border`; 買量 bars `--up`(紅) / 賣量
  bars `--down`(綠) as inline horizontal fill behind tabular 量/價; **▲▼ + sign** where signed;
  live-flash `--up-weak`/`--down-weak` on update (`LiveTickValue`).
- **逐筆 / 分K** — a `ChartWithDataSheet` `candle` at intraday TF (紅漲綠跌 candles, `--grid`/`--crosshair`);
  逐筆 tick stream as a `divide-y` list, 內盤/外盤 tinted `--down`/`--up`.
- **當沖率** — a single `--accent`-fill progress bar + tabular %.
- **馬賽克 for Free** — ladder + tick values blur under backdrop-blur + diagonal texture + lock chip +
  升級 CTA; the frame/labels stay sharp. **Delayed-snapshot caveat** (~5–20s) pinned as `<Caveat
  kind="currentness">`. Off-hours → last snapshot, static (no flash). Reduced-motion → no flash.

## Access & governance
Premium/Pro only → **馬賽克 teaser for Free** (frame sharp, ladder/values blurred, 升級 CTA). Carries
the **delayed-snapshot caveat** (~5–20s, not true real-time — §1.2). Non-trading; a quote display,
never a signal. Off-hours → last snapshot, static.
