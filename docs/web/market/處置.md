# 大盤 › 處置 (處置王 board)

Parent: [../market.md](../market.md). Row-2 view (台股) — the "處置王" market board.

## Content (`DispositionBoard`) — a card grid, not a plain table
4 buckets: **風險股 · 處置中 · 即將出關 · 自結發布** + **最快 N 日進處置** projection. 注意股 +
停資停券預告 alongside. Rendered as a **responsive card grid** of rich per-stock mini-cards (see
Visual design below), not a row table.

## Endpoint
`get_disposition_stocks`, `get_disposition_forecast` (the 最快N日 projection), `get_attention_stocks` —
all **public**. The 4 buckets map to these tools.

## Visual design (folded from the 處置王 references — dark-first)

Tokens/radius/spacing from [../design-system.md](../design-system.md) (card 16px, pad 20px, section
gap 24px, `VISUAL_DENSITY:6`). `--warn` is the board's signature accent (處置/注意/全額交割 status).

**Filters (two rows, above the grid).**
- **Bucket tabs with counts** — 風險股(139) · 處置中(34) · 即將出關(32) · 自結發布(32); segmented pill
  row, active = `--accent` underline/pill + shared-layout glide (`layoutId`); count badge = muted
  `--surface-2` pill, tabular-nums.
- **Source sub-filters** — 懸賞詢即時公告 / 處置股公告 / 注意股公告 / 自結公告 (segmented, secondary
  weight) + a **symbol search box** (input radius 10px, `--surface`, hairline `--border`).

**Grid.** 4-col desktop → 2-col (768–1279px) → 1-col mobile; 16px gaps. Each stock = a mini-card:
`--surface` bg, `1px --border`, radius 16px, pad 20px, tinted-shadow hover lift (adapts Kestrel
`.card-atmospheric`, no gradient blob).

**Per-card anatomy (top → bottom).**
- **Header row:** `名稱 代號` (16px/600, no mid-token break) + **上市/上櫃** badge (muted pill) +
  產業 **`SectorChip`** (電子零件/半導體/光學鏡頭… — sector token muted-tint bg + hairline, [design-system §2](../design-system.md)).
- **Price + change:** big tabular price (`--font-num`, 22–24px) + **▲▼ 漲跌%** in `--up`(漲)/`--down`(跌)
  — 紅漲綠跌, never color-alone. Right-aligned **stat column** (12px `--text-muted` labels, tabular
  values): 成交張數 · 成交值(億) · 三大法人 · 券資率% · 當沖%.
- **MA row:** MA5 · MA10 · MA20 values, tabular-nums, `--text-muted` labels.
- **「最快 N 日後進入處置 / 再次處置」** — the signature 處置王 metric (from `get_disposition_forecast`):
  a highlighted `--warn`-tinted inline label (bg `--warn`@~12% α + solid `--warn` text), tabular N.
- **Status icon strip:** `資 · 券 · 沖 · 警 · 處 · 注` flag chips — active flags `--warn` tint +
  solid text, inactive = ghost `--text-muted` hairline pill.
- **Interval badge (right):** orange **「5分盤 / 20分盤」** pill (`--warn` fill) — the 處置 matching-
  interval (5- or 20-min).
- **Footer note:** 處置期間 dates (`07/22–08/04`) OR a caveat line (「當沖率過高可能延長」/「疑似條件
  存在」/「回檔風險」) in 13px `--text-muted`, + `同 07/31` freshness stamp (`DataFreshnessBadge`).

```
┌─ 大立光 3008  [上市] [光學鏡頭] ───────────────┐
│ 2,415.00  ▼-3.20%          成交張數  4,182     │  ← price 紅漲綠跌 + stat column
│                            成交值(億)  10.1     │
│ MA5 2,460 · MA10 2,502 · MA20 2,548            │
│ ⚡ 最快 2 日後再次處置        [ 20分盤 ]        │  ← --warn label + interval pill
│ [資][券][沖][警][處][注]                        │  ← flag chips (--warn = active)
│ 處置期間 07/22–08/04 · 同 07/31                 │  ← footer note + freshness
└─────────────────────────────────────────────────┘
```

**States.** Loading = shimmer card ghosts (`.animate-shimmer`) in grid shape; empty bucket → 「此分類
目前無個股」. All flags/labels pair icon + text (never color-alone). tabular-nums throughout.

## Governance
Non-trading — a **risk/status board, not a signal**. The 「最快 N 日進處置」 is a **rule-based
projection** (交易條件推算), caveated as such — never a buy/sell cue. 全額交割股 flagged (`--warn`).
tabular-nums, 紅漲綠跌 + ▲▼ + sign, dark-first. `<Caveat kind="non-trading">` footer required.
