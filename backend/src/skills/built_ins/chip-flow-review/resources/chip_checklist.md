# Chip-flow review — detailed checklist (level-3 resource)

Load only if the caller's question needs finer granularity than the skill body's default
four-section structure.

- Foreign (外資): net-buy/sell streak length (consecutive days in the same direction), any
  single-day outlier vs the trailing 20-day average.
- Investment trust (投信): check for month-end/quarter-end 作帳 (book-dressing) timing — a
  spike near a reporting boundary is a *pattern to describe*, not a signal to act on.
- Dealer (自營): distinguish 自行 (proprietary) vs 避險 (hedging) if the source separates them;
  hedging flow answers a different question than proprietary conviction.
- Margin (融資)/short (融券): a rising margin balance into a falling price is a classic
  divergence worth naming descriptively (never as a trade signal).
- 分點 (broker branch, Sponsor-tier): look for concentration in a small number of branches vs.
  broad participation — report the observation, not an inference about "smart money".
