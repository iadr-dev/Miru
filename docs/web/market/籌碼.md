## Visual design
Each sub-card = a **`ChartWithDataSheet`** — visual in [../design-system.md §7.11](../design-system.md) +
[../market.md §5.1](../market.md). Nested sub-cards (§6.3), cards `--surface` + `1px --border` + radius 16px + pad 20px.

- **三大法人 買賣超** (`InstitutionalFlowSheet`) — `net-bar`: 買超 `--up`(紅) above zero / 賣超
  `--down`(綠) below, **+ ▲▼ + 張 labels**; summary table + daily sheet (sticky thead, tabular-nums,
  active row `--surface-2`).
- **法人買賣超排行** (`InstitutionalRanking`) — top net-buy/sell table, +買超 `--up` / −賣超 `--down`
  + ▲▼; ranked, `divide-y --border`.
- **融資券變化** (`MarginChangeSheet` + `MarginMaintenanceGauge` ⚑) — 增減 net-bar + 融資維持率 radial
  gauge with **`--warn` risk bands** (low maintenance = caution).
- **外資 / 主力 / 八大官股** — per-group net-bar; **sponsor → 馬賽克** (frame/date sharp, values blur
  under backdrop-blur + diagonal texture + lock chip + 升級 CTA).
- All signed cells `--up`/`--down` + ▲▼ never color-alone; `--chart-1..5` for any categorical overlay;
  `<Caveat kind="non-trading">` + 單位:張 + `DataFreshnessBadge`. Loading = chart + ghost-row shimmer.
