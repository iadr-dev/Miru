## ⚑ Backend reality (audited from code — [../DEVELOPMENT.md §4a](../DEVELOPMENT.md))
The financials data is real but the **tool names differ** from the table above. Actual tools:
`get_financial_statement` (balance-sheet/cash-flow line items), `get_month_revenue` (月營收),
`get_dividend_result` (除權除息結果) + `get_dividend_schedule`, `get_valuation_ratios` (PER/PBR/殖利率
daily — backs 估值 band), `get_corporate_action_events` (減資/下市/分割). **`get_company_profile` is
partial** — MOPS identity/ratio fields (chairman/capital/auditor/PER/EPS/yield…) are enumerated in
its `missing_fields` and **never populated** (no MOPS profile adapter), so 財務快照 built purely from
it will be sparse — prefer the dedicated tools above. **`get_self_settled_earnings`,
`get_buyback_status`, `get_investor_conferences` do NOT exist** — the 自結/庫藏股 and 法說會 sub-tabs
have no backend source today; defer them.

19	## Visual design
20	Every sub-tab is a **`ChartWithDataSheet`** instance — full visual in [../design-system.md §7.11](../design-system.md)
21	(ControlBar, `--grid`/`--crosshair`, sticky thead, tabular-nums, `--up`/`--down`+▲▼ signed cells,
22	`--chart-1..5` categorical, active row `--surface-2`, `<Caveat>` footer + unit + `DataFreshnessBadge`).
23	
24	- **Sub-tab bar** = segmented pill row, active `--accent` + shared-layout glide (§6.3).
25	- **Chart color mapping (categorical → `--chart-1..5`, signed → `--up`/`--down`+▲▼):**
26	  - 股利政策 grouped bar: 現金 `--chart-1` / 股票 `--chart-2`; 殖利率/配息率 as `--text-muted` overlay lines.
27	  - 營收趨勢 dual-line: 月營收 bar `--chart-1` (left axis) + **YoY% line signed** `--up`/`--down`+▲▼ (right axis).
28	  - 獲利能力: 毛利率 `--chart-1` / 營益率 `--chart-2` / 淨利率 `--chart-3` lines + EPS bar subpane.
29	  - 財務結構: 流動比/速動比/負債比 lines `--chart-1/2/3`; high 負債比 caption `--warn`.
30	  - 現金流量 `net-bar`: 營業/投資/融資 CF signed `--up`/`--down`+▲▼ + 自由現金流 line `--chart-4`.
31	- **自結/庫藏股 · 法說會** = plain `--surface` cards (not charts): 執行% bar (`--accent` fill), schedule
32	  list `divide-y --border`, deck links; 自結 flagged 「自結為公司初步數，未經會計師查核」.
33	- Cards radius 16px, pad 20px, tinted shadow; loading = chart-block + ghost-row shimmer; units 億/%.
34	
35	Non-trading (財務數據之描述). `--up`/`--down` on YoY/margin/CF deltas only, always **+ ▲▼ + sign**.
