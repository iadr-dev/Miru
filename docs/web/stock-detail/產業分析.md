15	## Visual design
16	Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). ASCII: [../stock-detail.md](../stock-detail.md) §4.
17	
18	- **同業比較** (`PeerCompaniesSection`) — sortable table, `divide-y --border`, tabular-nums; 市值 in
19	  兆/億, 月營收YoY / 多空 cells in `--up`(漲)/`--down`(跌) **+ ▲▼**; per-row `SectorChip` (sector-token
20	  muted tint + hairline); focus stock row = `--surface-2`; hover reveals spark; row → detail.
21	- **供應鏈關係圖** (`SupplyChainGraph`) — 上游◄焦點►下游 graph; nodes **sector-tinted** (sector tokens),
22	  focus node `--accent` ring; edges = `.flow-line` (dash-draw on mount, direction drift), reduced-motion
23	  → static; node hover highlights edges + tooltip; click → detail.
24	- **多空訊號** (`BullBearTab`) — 偏多/偏空 horizontal micro-bar (`--up`/`--down` fill + % label) + 看多/
25	  看空 signal lists; each signal a 描述 line ("站上 20MA"), `--warn` caption 「均線描述，非買賣訊號」.
26	- **產業鏈資金流** (`IndustryFlowChart`) — in/out `net-bar` (紅漲綠跌 + ▲▼, `--grid` for the neutral
27	  zero axis/gridlines); 分點-derived → **馬賽克** for Free (frame sharp, bars blurred, lock chip + CTA).
28	- Cards `--surface` + `1px --border` + radius 16px + tinted shadow; `<Caveat>` footer on each.
29	
30	## Governance
31	多空訊號 is a **描述 of MA positions, never a buy/sell signal** (§7 non-trading). 產業鏈資金流 (分點-
32	derived) = 🔒 for Free. Peer 多空 bands carry the non-trading caveat.
