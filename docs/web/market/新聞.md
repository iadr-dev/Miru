# 大盤 › 新聞 (news)

Parent: [../market.md](../market.md). Row-2 view (台股).

## Blocks
| Block | Content | Component | Endpoint |
|-------|---------|-----------|----------|
| 市場新聞 | **即時新聞 / 財經新聞 segmented** (fast RSS vs curated) + sentiment | `MarketNews` | `get_stock_news?category=realtime\|finance` (topic) |
| 名人事件 | 名人 avatar + linked events feed | `FigureEventsFeed` | `get_figure_events` |

All `public`. Non-trading framing; external claims cited. PTT Beauty/Gossiping never here (mascot only).

## Visual design
Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Cards `--surface`
+ `1px --border` + tinted shadow. Mirrors the stock 相關新聞 visual for consistency.

- **市場新聞** (`MarketNews`) — 即時/財經 **segmented tabs** (active `--accent` + shared-layout glide);
  `divide-y --border` feed, each row: 時間 (tabular `--text-muted`) · 來源 chip · 標題 (16px/1.7) ·
  **情緒 chip** (看多 `--up`-tint / 看空 `--down`-tint / 中性 `--text-muted`, always text-labelled).
- **名人事件** (`FigureEventsFeed`) — `FigureAvatar` round + linked event + affected stock/theme chips;
  non-analysis framed. This is a **preview** (top ~3–5) with a 「更多」 link to the full
  [名人 view](名人.md); the standalone 名人 Row-2 view is the complete feed (same `get_figure_events`
  source, so it reads as one feed surfaced at two depths, not a duplicate).
- States: shimmer list rows; empty → 「暫無新聞」.
