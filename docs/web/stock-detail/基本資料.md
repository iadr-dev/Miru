18	## Visual design
19	Tokens/radius/spacing from [../design-system.md](../design-system.md) (card 16px, pad 20px, section
20	gap 24px). All cards = `--surface` + `1px --border` + radius 16px + tinted shadow; 2-col grid ≥1280px.
21	
22	- **個股資訊卡 / 財務快照** (`StockInfoTab`) — label/value grid, `divide-y --border`; labels 13px
23	  `--text-muted`, values tabular-nums (`--font-num`); 季營收+YoY / 三率 / 殖利率 deltas in `--up`(漲)/
24	  `--down`(跌) **+ ▲▼**. 產業 = `SectorChip` (sector-token muted tint + hairline).
25	- **集團/轉投資/大股東** (`PeerCompaniesSection` relations) — `divide-y --border` list, row → detail.
26	- **內部人/董監持股·質押比** (`HoldersInsidersSection`) — de-identified rows; **high 質押比 → `--warn`**
27	  tinted cell + text label (never color-alone). No naming table.
28	- **處置/注意 banner** — full-width `--warn`-tinted strip (bg `--warn`@~12% α + solid text + flag icon)
29	  above the fold when flagged; 最快N日 tabular.
30	- **公告/事件 stream** (`MaterialAnnouncementsCard`) — timeline rows, category + sentiment chips
31	  (合約/M&A/訴訟… muted-tint pills), `divide-y --border`, newest first.
32	- **被 N 支 ETF 持有** (`EtfHoldersCard`) — table, 比重/張數 +增減 in `--up`/`--down` + ▲▼; ETF-type
33	  filter chips; 分點-derived (active) side → 馬賽克 for Free.
34	- **ESG 風險** (`EsgRiskCard`) — **hidden entirely when null** (coverage-gated), no empty scaffold.
35	- States: shimmer skeletons in card shapes; `<Caveat>` footer on analytical cards.
36	
37	## Governance
38	Insider data = de-identified risk flag, never a naming-and-shaming table. ESG/analyst are
39	coverage-gated → show nothing rather than empty scaffolding. 分點-derived ETF-holding side = 🔒 mosaic.
