## Visual design
Every sub-tab is a **`ChartWithDataSheet`** instance — full visual in [../design-system.md §7.11](../design-system.md)
(ControlBar, `--grid`/`--crosshair`, sticky thead, tabular-nums, `--up`/`--down`+▲▼ signed cells,
`--chart-1..5` categorical, active row `--surface-2`, `<Caveat>` footer + unit + `DataFreshnessBadge`).

- **Sub-tab bar** = segmented pill row, active `--accent` + shared-layout glide (§6.3).
- **Chart color mapping (categorical → `--chart-1..5`, signed → `--up`/`--down`+▲▼):**
  - 股利政策 grouped bar: 現金 `--chart-1` / 股票 `--chart-2`; 殖利率/配息率 as `--text-muted` overlay lines.
  - 營收趨勢 dual-line: 月營收 bar `--chart-1` (left axis) + **YoY% line signed** `--up`/`--down`+▲▼ (right axis).
  - 獲利能力: 毛利率 `--chart-1` / 營益率 `--chart-2` / 淨利率 `--chart-3` lines + EPS bar subpane.
  - 財務結構: 流動比/速動比/負債比 lines `--chart-1/2/3`; high 負債比 caption `--warn`.
  - 現金流量 `net-bar`: 營業/投資/融資 CF signed `--up`/`--down`+▲▼ + 自由現金流 line `--chart-4`.
- **自結/庫藏股 · 法說會** = plain `--surface` cards (not charts): 執行% bar (`--accent` fill), schedule
  list `divide-y --border`, deck links; 自結 flagged 「自結為公司初步數，未經會計師查核」.
- Cards radius 16px, pad 20px, tinted shadow; loading = chart-block + ghost-row shimmer; units 億/%.

Non-trading (財務數據之描述). `--up`/`--down` on YoY/margin/CF deltas only, always **+ ▲▼ + sign**.
