## ⚑ Backend reality (audited from code — [../DEVELOPMENT.md §4a](../DEVELOPMENT.md))
**None of the three blocks has a working backend today.** `get_sector_indices`, `/market/sectors`,
and `/market/advance-decline` are **not built** (no backing tools). 類股熱力圖, 產業別漲跌, and
個股漲跌分佈 have no REST source — build them as coverage-empty states until the sector/breadth tools land.

14	## Visual design
15	Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Cards `--surface`
16	+ `1px --border` + tinted shadow.
17	
18	- **類股熱力圖** (`TreemapHeat`) — tiles sized by 成交值, colored by 漲跌 **magnitude tint** across the
19	  `--up`(漲)→neutral→`--down`(跌) scale; each tile shows 名稱 + **▲▼ +%** label (never color-alone).
20	  Big movers get a subtle `breathe` opacity pulse (reduced-motion → none); hover → tile scales up
21	  (`--surface-2` border); click → `SectorStocksModal`.
22	- **產業別漲跌** (`SectorBar`) — `net-bar` per sector, 上漲 `--up` / 下跌 `--down` + ▲▼ + % label;
23	  上市/上櫃 toggle (segmented); datasheet sheet below (tabular-nums).
24	- **個股漲跌分佈** (`AdvanceDeclineHistogram`) — bucket histogram (>5%/3-5%/…/<-5%), bars tinted along
25	  the 紅漲綠跌 scale + 家數 count labels.
26	- States: shimmer treemap/block ghosts; `<Caveat kind="currentness">` footer.
