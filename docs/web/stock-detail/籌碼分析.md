17	## Visual design
18	Every sub-tab is a **`ChartWithDataSheet`** instance — full visual in [../design-system.md §7.11](../design-system.md).
19	Sub-tab bar = segmented pill row, active `--accent` + shared-layout glide; `分點🔒` shows the lock glyph
20	**before** click (learnable paywall).
21	
22	- **Chart = `net-bar`** around zero: 買超 `--up`(紅) above, 賣超 `--down`(綠) below, **always ▲▼ +
23	  張 value labels** (never color-alone); optional price overlay line `--chart-4`. `--grid` gridlines,
24	  `--crosshair` dashed sync to sheet row.
25	- **法人** (`InstitutionalFlowSheet`) — summary table (外資/投信/自營/自營避險: 買進/賣出/買賣超) above
26	  the net-bar; 連買/連賣 streak badge; 季底作帳 spikes get a `--warn` low-confidence caption.
27	- **融資券** (`MarginChangeSheet`) · **借券** (adapts `MarginChangeSheet`) — 增減 net-bar + 餘額/資券比
28	  summary; datasheet tabular-nums.
29	- **股權分散** (`DispersionTrend`) — multi-line 大戶/中實戶/散戶 人數 `--chart-1/2/3` (categorical, no
30	  signed color); 千張大戶比率% as a highlighted line; 增減 sheet in `--up`/`--down`+▲▼.
31	- **分點** (adapts `InstitutionalFlowSheet`) — top-5 買/賣 分點 + 八大官股; sponsor → **馬賽克**:
32	  券商名稱/日期 columns stay **sharp**, 張數/淨額 values blur under backdrop-blur + diagonal texture +
33	  lock chip + 升級 CTA.
34	- Datasheet: sticky thead, active/hovered row `--surface-2` (`aria-current`), tabular-nums; `<Caveat
35	  kind="non-trading">` footer + 單位:張 + `DataFreshnessBadge`. Loading = chart-block + ghost-row shimmer.
36	
37	## Governance
38	三大法人 **total** is public; 分點/官股 = **sponsor → 馬賽克** for Free (frame sharp, values blurred,
39	one calm CTA). Sub-tab shows `分點🔒` glyph pre-click (learnable paywall). 季底作帳 flow spikes flagged
40	lower-confidence. All 籌碼 reads are **descriptive, non-trading**; 借券 tool ⚑ TBD in module 03.
