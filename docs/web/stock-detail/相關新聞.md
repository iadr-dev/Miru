## ⚑ Backend reality (audited from code — [../DEVELOPMENT.md §4a/§4d](../DEVELOPMENT.md))
The only per-stock news tool that exists is **`get_finmind_stock_news`** (FinMind dataset, one day at
a time). **`get_stock_news`, `get_social_buzz`, `get_figure_events`, `get_trending_buzz` do NOT
exist** — there are no RSS/GDELT/Finnhub/PTT/名人 news tools. So 即時/財經 split, PTT 討論, and 名人事件
have **no dedicated backend today**; `web_search` is the general fallback via the agent path. Ship
財經新聞 off `get_finmind_stock_news`; treat the other sub-tabs as design-forward until their sources land.

15	## Visual design
16	Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Sub-tab bar =
17	segmented pill row, active `--accent` + shared-layout glide (§6.3).
18	
19	- **News feed** (`MarketNews`) — `divide-y --border` list on `--surface`, newest first; each row:
20	  時間 (13px `--text-muted`, tabular) · 來源 chip · 標題 (16px/1.7) · **情緒 chip** (看多 `--up`-tint /
21	  看空 `--down`-tint / 中性 `--text-muted` — always with a text label, never color-alone). Row → source.
22	- **即時新聞** = denser, minimal chrome (fast RSS); **財經新聞** = curated, topic chip added.
23	- **PTT 討論** = buzz card: 推文數/post-volume mini-bar + crowd sentiment, with a **`--warn` "未經證實
24	  散戶意見" banner** pinned on the card. PTT Beauty/Gossiping never here.
25	- **名人事件** (`FigureEventsFeed`) — figure avatar (`FigureAvatar`, round) + linked event + affected
26	  stock/theme chips; non-analysis framed.
27	- States: loading = shimmer list rows; empty → 「近期無相關新聞」.

29	## Governance
30	PTT buzz is **flagged unverified retail opinion**, excluded from investment rationale (guardrail).
31	PTT Beauty/Gossiping (`get_trending_buzz`) is **never** here — mascot/whimsy only. News claims are
32	external → non-trading framing; no 明牌/目標價 restatement.
