# 個股 › 技術分析 (technical)

Parent: [../stock-detail.md](../stock-detail.md). The K線 workbench — a `ChartWithDataSheet` (§7.11)
`candle` instance with the richest control set.

## K線 chart (`KLineChart`, lightweight-charts)
- **Candles** — 紅漲綠跌 bodies (漲 red / 跌 green); **還原股價 toggle** (adjusted vs raw).
- **MA overlays** — MA5/10/20/60/120/240 (`--chart-1..6`, one per line), toggle chips.
- **Subpanes** — 量 (volume, 紅漲綠跌), **KD · MACD · RSI · 布林** toggle panes (stacked).
- **Structure markers** — 支撐/壓力 levels + N波回檔 (`?set=sr,wave`); K線型態 (24 patterns, `?set=candlestick`, labelled 描述 +1看多/−1看空).
- **Overlays** — 三大法人 / 主力成本 chips (from 籌碼).
- **Timeframe** — 日/週/月 · 1M / 3M / 6M / 1Y / YTD / 5Y.

## Datasheet (展開歷史)
`日期 · 開 · 高 · 低 · 收 · 漲跌% · 量(張)` — tabular-nums, crosshair↔row sync, ←/→ keyboard.

## Endpoint
`GET /analytics/{s}/indicators?set=ma,kd,macd,rsi,bollinger,volume,sr,wave,candlestick`
+ price history (`Week`/`Month`/`Stock10Year` for TF). All **public** compute.

## Visual design
The richest **`ChartWithDataSheet`** `candle` instance — full shell visual in [../design-system.md §7.11](../design-system.md).

- **Candles (`KLineChart`, lightweight-charts):** 漲 body `--up`(紅) / 跌 body `--down`(綠) — 紅漲綠跌;
  crosshair `--crosshair` dashed, gridlines `--grid`. Volume subpane bars 紅漲綠跌 too.
- **MA overlays** = distinct categorical lines `--chart-1..6` (MA240 uses the 6th, `--chart-6`); toggle chips
  (pill 999px, active `--accent`). Legend chips in the ControlBar show each MA's color + value.
- **Subpanes** (KD · MACD · RSI · 布林) stack below, toggle chips; each uses `--chart-1..5` for its
  lines (never `--up`/`--down` — these are categorical indicators, not signed price).
- **Structure markers** — 支撐/壓力 as `--text-muted` dashed h-lines + label; N波 / K線型態 as small
  `--accent`-hairline annotation pins with 描述 tooltip (+1看多/−1看空 as label text, not color-alone).
- **ControlBar** — 還原股價 toggle · MA/indicator chips · `[日|週|月]` + `1M 3M 6M 1Y YTD 5Y` range
  pills (active `--accent`) · `⤓` CSV (Premium). **Timeframe drives one refetch**, persisted in URL.
- **Datasheet (展開歷史 ▾):** `日期·開·高·低·收·漲跌%·量(張)`, sticky thead, tabular-nums, 漲跌% cell
  `--up`/`--down`+▲▼; crosshair ↔ row sync (←/→ chart, ↑/↓ sheet, one `activeIndex`); active row
  `--surface-2` `aria-current`. Reduced-motion → crosshair snaps.
- **States** — loading = shaped skeleton (candle block + ghost rows), never spinner. `<Caveat
  kind="non-trading">` footer + 單位 + `DataFreshnessBadge`. All public compute (no mosaic here).

## Governance
A KD golden cross / bullish engulfing is a **描述 of the chart** ("KD 低檔黃金交叉"), **never "buy"**
(§7 non-trading). Pattern +1/−1 = observation label, not a position instruction. Non-trading `<Caveat>` footer.
