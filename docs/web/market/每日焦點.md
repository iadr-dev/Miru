## Visual design
12-col grid on `--bg`; cards `--surface` + `1px --border` + radius 16px + pad 20px + tinted shadow.
Shell + `ChartWithDataSheet` visual: [../market.md §5](../market.md). Tokens: [../design-system.md](../design-system.md).

- **大盤概況** — 加權/櫃買 `IndexCard`s span 4-col each: name 14px `--text-muted` + big value 24px
  `--font-num` + **▲▼ pts +%** in `--up`(漲)/`--down`(跌); `FearGreedGauge` radial (green→red sweep,
  needle eases on load, no re-anim on tick).
- **指數 即時** (`IndexIntraday`) — full-width intraday line + volume subpane; 即時/貢獻/K線/籌碼/外資
  sub-tabs (segmented, active `--accent`); live flash `--up-weak`/`--down-weak`.
- **漲跌家數** (`AdvanceDeclineHistogram`) — diverging bar (上漲 `--up` / 下跌 `--down` + count labels)
  + bucket histogram; 家數 tabular, always **+ count** never color-alone.
- **指數貢獻排行** (`IndexContributionTable`) — two-col diverging table, +貢獻 `--up` / −貢獻 `--down`
  + ▲▼ + 點數; ranked, tabular-nums.
- **AI 精選 Top-N** (`StrengthRanking`) — ranked list + factor chips; header 「清單非推薦」 `--warn`
  caption; sponsor factor columns → 馬賽克 for Free.
- **熱門股** (`HotStocks`) — 漲停/成交值/量 segmented tabs; 處置 flag chip `--warn`.
- **本週行事曆** (`MarketCalendar`) — span-6 card: next 5–7 trading days of market-wide events
  (除權息/法說/股東會/期貨結算/index rebalance/IPO), grouped by date, each row `事件類型` chip +
  代號名稱 → Stock Detail; event-state ([18](../../backend/modules/18-calendar-events.md)) shown as a
  muted `scheduled/expected/confirmed` pill. This is the market-wide events surface the top-level
  Calendar nav removal ([../README.md](../README.md) primary-nav) points at; per-stock events live in
  Stock Detail › 研究圖表. Non-trading (a schedule, not a cue).
- **總經指標帶** (`MacroStrip`) — full-width single-row strip of mini-stats (S&P/Nasdaq/匯率/債/黃金/
  夜盤/F-G), each ▲▼ + value tabular.
- States: shimmer (index-card ghosts + chart block + ghost rows); `<Caveat>` per block.
