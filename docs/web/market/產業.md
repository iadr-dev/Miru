## ⚑ Backend reality (audited from code — [../DEVELOPMENT.md §4a](../DEVELOPMENT.md))
- **產業鏈資金流** — real: `get_industry_money_flow` (Sponsor) → `GET /market/industry-flow`.
- **類股輪動** — `get_sector_indices` does **NOT exist**; no sector time-series tool → no source today.
- **主題總覽** — the theme *lookup* is real (`get_theme_members`/`get_symbol_themes`/`get_theme_tiers`
  → `/themes/*`, public), but **`get_themes`, `get_theme_flow`, and `/analytics/themes`
  (LLM-discovered concept themes + 資金流向) do NOT exist**. Build 主題總覽 off the real `/themes/*`
  membership/tier lookup; the discovery + flow layer is design-only.
