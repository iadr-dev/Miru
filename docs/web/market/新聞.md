## ⚑ Backend reality (audited from code — [../DEVELOPMENT.md §4d](../DEVELOPMENT.md))
`get_stock_news` and `get_figure_events` do **NOT exist** — the only news tool is
`get_finmind_stock_news` (per-stock FinMind dataset) plus general `web_search`. Market-wide 市場新聞
and 名人事件 have **no dedicated backend today**; build them via the agent/`web_search` path or defer.
