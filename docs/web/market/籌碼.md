17	## Visual design
18	Each sub-card = a **`ChartWithDataSheet`** — visual in [../design-system.md §7.11](../design-system.md) +
19	[../market.md §5.1](../market.md). Nested sub-cards (§6.3), cards `--surface` + `1px --border` + radius 16px + pad 20px.
20	
21	- **三大法人 買賣超** (`InstitutionalFlowSheet`) — `net-bar`: 買超 `--up`(紅) above zero / 賣超
22	  `--down`(綠) below, **+ ▲▼ + 張 labels**; summary table + daily sheet (sticky thead, tabular-nums,
23	  active row `--surface-2`).
24	- **法人買賣超排行** (`InstitutionalRanking`) — top net-buy/sell table, +買超 `--up` / −賣超 `--down`
25	  + ▲▼; ranked, `divide-y --border`.
26	- **融資券變化** (`MarginChangeSheet` + `MarginMaintenanceGauge` ⚑) — 增減 net-bar + 融資維持率 radial
27	  gauge with **`--warn` risk bands** (low maintenance = caution).
28	- **外資 / 主力 / 八大官股** — per-group net-bar; **sponsor → 馬賽克** (frame/date sharp, values blur
29	  under backdrop-blur + diagonal texture + lock chip + 升級 CTA).
30	- All signed cells `--up`/`--down` + ▲▼ never color-alone; `--chart-1..5` for any categorical overlay;
31	  `<Caveat kind="non-trading">` + 單位:張 + `DataFreshnessBadge`. Loading = chart + ghost-row shimmer.
