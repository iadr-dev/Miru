# 個股 › 智能摘要 (含多空評分) (ai)

Parent: [../stock-detail.md](../stock-detail.md). **多空評分 lives here** — the gauge is the
quantitative half of the AI read; the tab reads top→bottom as one story.

## Layout (top → bottom)
1. **多空 Score Gauge** (design-system §7.1) — radial arc (偏空→中性→偏多, 紅漲綠跌 sweep) + needle +
   band label + numeric + **factor micro-bars** (動能/趨勢/估值/品質/籌碼) + **profile toggle
   (swing/position)** + regime + over-extension caveat. `GET /analytics/{s}/score?profile=swing|position`.
   **Public** — but the 籌碼 factor's 分點 sub-signal masks for Free (composite recomputed over available
   factors + "籌碼因子部分未解鎖" disclosure, never silently degraded).
2. **AI 智能摘要** — 市場定位 headline (sharp) + factor-grounded narrative + **SWOT** (each bullet
   cites a datum). `GET /analytics/{s}/summary`. **Premium+** → SWOT body under 馬賽克 for Free
   (headline stays sharp).

## Access
Mixed: gauge public (分點 factor masks), summary/SWOT Premium+. Header band-pill `[偏多 72]` deep-links
here + scrolls to the gauge.

## Visual design
The tab reads top→bottom as one story on a single `--surface` column (cards radius 16px, pad 20px,
`1px --border`, tinted shadow). Gauge visual = [../design-system.md §7.1](../design-system.md).

- **多空 Score Gauge** — radial arc, **偏空→中性→偏多 sweeping green→neutral→red** (紅漲綠跌 convention);
  needle **springs to value on load, never re-animates on a quote tick**; reduced-motion → static at
  value. Big band label + numeric centered (`--font-num`, `--up`/`--down`-tinted by band).
- **Factor micro-bars** (動能/趨勢/估值/品質/籌碼) — horizontal bars beneath, each tinted + tabular
  value; low 估值 (value guard) → `--warn` tint (追高 caution). **Always shown** (never bare score).
- **Profile toggle** (swing/position) = segmented pill (active `--accent`); regime + over-extension
  caveat inline. 籌碼 factor's 分點 sub-signal masked for Free → "籌碼因子部分未解鎖" disclosure chip
  (composite recomputed, never silently degraded).
- **AI 智能摘要** — 市場定位 headline stays **sharp** (16px/1.7 CJK); factor-grounded narrative + SWOT
  4-quadrant grid. For Free, **SWOT body under 馬賽克** (backdrop-blur + diagonal texture + lock chip +
  升級 CTA); headline + quadrant frame stay sharp.
- Required footer: "AI-generated summary of data, not advice" + currentness `<Caveat>`.

## Governance (strictest — §7)
Descriptive not prescriptive: 偏多/中性/偏空 describes what factors show, **never 買/賣/target/sizing**.
Score always ships its **factor breakdown + 描述** (show the work). SWOT "Opportunity" = factor
observation, never 進場點. "AI-generated summary of data, not advice" footer + currentness caveat mandatory.
