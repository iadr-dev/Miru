# 大盤 › 產業 (industry)

Parent: [../market.md](../market.md). Row-2 view (台股).

## Blocks
| Block | Chart | Component | Endpoint | Access |
|-------|-------|-----------|----------|--------|
| 產業鏈資金流 | in/out bars (sector money rotation) | `IndustryFlowChart` | `get_industry_money_flow` | 🔒 mosaic |

Themes = tag, not a scored signal (non-trading). 產業鏈資金流 (分點-derived) 🔒. 紅漲綠跌, tabular-nums.

## Visual design
Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Cards `--surface`
+ `1px --border` + tinted shadow.

- **產業鏈資金流** (`IndustryFlowChart`) — in/out `net-bar` (sector money rotation), 流入 `--up` /
  流出 `--down` + ▲▼ + 億 labels; 分點-derived → **馬賽克** for Free (bars blur, sector labels sharp).
- **類股輪動** (`SectorRotation`) — multi-line sector momentum over time, categorical `--chart-1..5`
  (**not** 紅漲綠跌 — these are sector series, not signed price); `--grid`/`--crosshair` sync.
- **主題總覽** (`ThemeCards`) — theme cards with 資金流向 mini-bar + member `SectorChip`s (sector-token
  muted tint + hairline); click → `/screener?theme=`. **Premium+** → 馬賽克 for Free. Themes framed as
  tag, not a scored signal (non-trading caption).
- States: shimmer card/chart ghosts; `<Caveat>` per block.
