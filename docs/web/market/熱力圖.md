## Visual design
Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px). Cards `--surface`
+ `1px --border` + tinted shadow.

- **類股熱力圖** (`TreemapHeat`) — tiles sized by 成交值, colored by 漲跌 **magnitude tint** across the
  `--up`(漲)→neutral→`--down`(跌) scale; each tile shows 名稱 + **▲▼ +%** label (never color-alone).
  Big movers get a subtle `breathe` opacity pulse (reduced-motion → none); hover → tile scales up
  (`--surface-2` border); click → `SectorStocksModal`.
- **產業別漲跌** (`SectorBar`) — `net-bar` per sector, 上漲 `--up` / 下跌 `--down` + ▲▼ + % label;
  上市/上櫃 toggle (segmented); datasheet sheet below (tabular-nums).
- **個股漲跌分佈** (`AdvanceDeclineHistogram`) — bucket histogram (>5%/3-5%/…/<-5%), bars tinted along
  the 紅漲綠跌 scale + 家數 count labels.
- States: shimmer treemap/block ghosts; `<Caveat kind="currentness">` footer.
