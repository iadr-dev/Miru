# 大盤 › 名人 (figure events)

Parent: [../market.md](../market.md). Row-2 view (台股).

## Content (`FigureEventsFeed`)
Named-figure event feed (黃仁勳/馬斯克/巴菲特/央行首長…) — avatar + linked news + affected stocks/themes.
Scanned from ingested news (module 20 §5C `figure_events`).

## Endpoint
`get_figure_events` — **public**.

## Visual design
Tokens/radius from [../design-system.md](../design-system.md) (card 16px, pad 20px).

- **`FigureEventsFeed`** — vertical feed on `--surface`, `divide-y --border`; each event row:
  **`FigureAvatar`** (round, 40px) + 名字 (15px/600) + 時間 (tabular `--text-muted`) · event 標題
  (16px/1.7) · linked-coverage source chips · affected **stock/theme chips** (`SectorChip` /
  code+name pills, sector-token muted tint + hairline) → click to detail.
- **Non-analysis framing** — a `--text-muted` "事件與相關報導，非投資建議" caption, no 紅漲綠跌 scoring
  on the figure (context, not signal). Loading = shimmer avatar+row ghosts; empty → 「近期無名人事件」.

## Governance
Non-analysis framed — events + linked coverage, **not** a recommendation. External/attributed; a
figure's remark is context, never our view.
