## ⚑ Backend reality (audited from code — [../DEVELOPMENT.md §4a](../DEVELOPMENT.md))
Most blocks here reference **routes/tools that do NOT exist**: `/market/overview`,
`/market/advance-decline`, `/market/index-contribution`, `/market/sectors` and the tools
`get_market_context`, `get_advance_decline`, `get_index_contribution`, `get_sector_indices`,
`get_disposition_stocks` are **not built**. So 大盤概況, 漲跌家數 breadth, 指數貢獻排行, and the 熱門股
處置 flag have **no REST source today** — build them as coverage-empty/degraded states until the
backend lands them. **What IS real** for this view: `AI 精選 Top-N` → `GET /analytics/rankings`;
總經指標帶 → `GET /macro`; index quotes → `GET /quote(/stream)`. 本週行事曆 has **no `/calendar`
route** — only the Sponsor `get_calendar_events` agent tool (feed-only 除權息+CB; AGM/法說 are gaps).

19	## Visual design
20	12-col grid on `--bg`; cards `--surface` + `1px --border` + radius 16px + pad 20px + tinted shadow.
21	Shell + `ChartWithDataSheet` visual: [../market.md §5](../market.md). Tokens: [../design-system.md](../design-system.md).
22	
23	- **大盤概況** — 加權/櫃買 `IndexCard`s span 4-col each: name 14px `--text-muted` + big value 24px
24	  `--font-num` + **▲▼ pts +%** in `--up`(漲)/`--down`(跌); `FearGreedGauge` radial (green→red sweep,
25	  needle eases on load, no re-anim on tick).
26	- **指數 即時** (`IndexIntraday`) — full-width intraday line + volume subpane; 即時/貢獻/K線/籌碼/外資
27	  sub-tabs (segmented, active `--accent`); live flash `--up-weak`/`--down-weak`.
28	- **漲跌家數** (`AdvanceDeclineHistogram`) — diverging bar (上漲 `--up` / 下跌 `--down` + count labels)
29	  + bucket histogram; 家數 tabular, always **+ count** never color-alone.
30	- **指數貢獻排行** (`IndexContributionTable`) — two-col diverging table, +貢獻 `--up` / −貢獻 `--down`
31	  + ▲▼ + 點數; ranked, tabular-nums.
32	- **AI 精選 Top-N** (`StrengthRanking`) — ranked list + factor chips; header 「清單非推薦」 `--warn`
33	  caption; sponsor factor columns → 馬賽克 for Free.
34	- **熱門股** (`HotStocks`) — 漲停/成交值/量 segmented tabs; 處置 flag chip `--warn`.
35	- **本週行事曆** (`MarketCalendar`) — span-6 card: next 5–7 trading days of market-wide events
36	  (除權息/法說/股東會/期貨結算/index rebalance/IPO), grouped by date, each row `事件類型` chip +
37	  代號名稱 → Stock Detail; event-state ([18](../../backend/modules/18-calendar-events.md)) shown as a
38	  muted `scheduled/expected/confirmed` pill. This is the market-wide events surface the top-level
39	  Calendar nav removal ([../README.md](../README.md) primary-nav) points at; per-stock events live in
40	  Stock Detail › 研究圖表. Non-trading (a schedule, not a cue).
41	- **總經指標帶** (`MacroStrip`) — full-width single-row strip of mini-stats (S&P/Nasdaq/匯率/債/黃金/
42	  夜盤/F-G), each ▲▼ + value tabular.
43	- States: shimmer (index-card ghosts + chart block + ghost rows); `<Caveat>` per block.
