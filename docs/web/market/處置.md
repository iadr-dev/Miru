1	# 大盤 › 處置 (處置王 board)
2	
3	Parent: [../market.md](../market.md). Row-2 view (台股) — the "處置王" market board.
4	
5	## Content (`DispositionBoard`) — a card grid, not a plain table
6	4 buckets: **風險股 · 處置中 · 即將出關 · 自結發布** + **最快 N 日進處置** projection. 注意股 +
7	停資停券預告 alongside. Rendered as a **responsive card grid** of rich per-stock mini-cards (see
8	Visual design below), not a row table.
9	
10	## Endpoint
11	`get_disposition_stocks`, `get_disposition_forecast` (the 最快N日 projection), `get_attention_stocks` —
12	all **public**. The 4 buckets map to these tools.
13	
14	## Visual design (folded from the 處置王 references — dark-first)
15	
16	Tokens/radius/spacing from [../design-system.md](../design-system.md) (card 16px, pad 20px, section
17	gap 24px, `VISUAL_DENSITY:6`). `--warn` is the board's signature accent (處置/注意/全額交割 status).
18	
19	**Filters (two rows, above the grid).**
20	- **Bucket tabs with counts** — 風險股(139) · 處置中(34) · 即將出關(32) · 自結發布(32); segmented pill
21	  row, active = `--accent` underline/pill + shared-layout glide (`layoutId`); count badge = muted
22	  `--surface-2` pill, tabular-nums.
23	- **Source sub-filters** — 懸賞詢即時公告 / 處置股公告 / 注意股公告 / 自結公告 (segmented, secondary
24	  weight) + a **symbol search box** (input radius 10px, `--surface`, hairline `--border`).
25	
26	**Grid.** 4-col desktop → 2-col (768–1279px) → 1-col mobile; 16px gaps. Each stock = a mini-card:
27	`--surface` bg, `1px --border`, radius 16px, pad 20px, tinted-shadow hover lift (adapts Kestrel
28	`.card-atmospheric`, no gradient blob).
29	
30	**Per-card anatomy (top → bottom).**
31	- **Header row:** `名稱 代號` (16px/600, no mid-token break) + **上市/上櫃** badge (muted pill) +
32	  產業 **`SectorChip`** (電子零件/半導體/光學鏡頭… — sector token muted-tint bg + hairline, [design-system §2](../design-system.md)).
33	- **Price + change:** big tabular price (`--font-num`, 22–24px) + **▲▼ 漲跌%** in `--up`(漲)/`--down`(跌)
34	  — 紅漲綠跌, never color-alone. Right-aligned **stat column** (12px `--text-muted` labels, tabular
35	  values): 成交張數 · 成交值(億) · 三大法人 · 券資率% · 當沖%.
36	- **MA row:** MA5 · MA10 · MA20 values, tabular-nums, `--text-muted` labels.
37	- **「最快 N 日後進入處置 / 再次處置」** — the signature 處置王 metric (from `get_disposition_forecast`):
38	  a highlighted `--warn`-tinted inline label (bg `--warn`@~12% α + solid `--warn` text), tabular N.
39	- **Status icon strip:** `資 · 券 · 沖 · 警 · 處 · 注` flag chips — active flags `--warn` tint +
40	  solid text, inactive = ghost `--text-muted` hairline pill.
41	- **Interval badge (right):** orange **「5分盤 / 20分盤」** pill (`--warn` fill) — the 處置 matching-
42	  interval (5- or 20-min).
43	- **Footer note:** 處置期間 dates (`07/22–08/04`) OR a caveat line (「當沖率過高可能延長」/「疑似條件
44	  存在」/「回檔風險」) in 13px `--text-muted`, + `同 07/31` freshness stamp (`DataFreshnessBadge`).
45	
46	```
47	┌─ 大立光 3008  [上市] [光學鏡頭] ───────────────┐
48	│ 2,415.00  ▼-3.20%          成交張數  4,182     │  ← price 紅漲綠跌 + stat column
49	│                            成交值(億)  10.1     │
50	│ MA5 2,460 · MA10 2,502 · MA20 2,548            │
51	│ ⚡ 最快 2 日後再次處置        [ 20分盤 ]        │  ← --warn label + interval pill
52	│ [資][券][沖][警][處][注]                        │  ← flag chips (--warn = active)
53	│ 處置期間 07/22–08/04 · 同 07/31                 │  ← footer note + freshness
54	└─────────────────────────────────────────────────┘
55	```
56	
57	**States.** Loading = shimmer card ghosts (`.animate-shimmer`) in grid shape; empty bucket → 「此分類
58	目前無個股」. All flags/labels pair icon + text (never color-alone). tabular-nums throughout.
59	
60	## Governance
61	Non-trading — a **risk/status board, not a signal**. The 「最快 N 日進處置」 is a **rule-based
62	projection** (交易條件推算), caveated as such — never a buy/sell cue. 全額交割股 flagged (`--warn`).
63	tabular-nums, 紅漲綠跌 + ▲▼ + sign, dark-first. `<Caveat kind="non-trading">` footer required.
