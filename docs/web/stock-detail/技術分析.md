21	## Visual design
22	The richest **`ChartWithDataSheet`** `candle` instance — full shell visual in [../design-system.md §7.11](../design-system.md).
23	
24	- **Candles (`KLineChart`, lightweight-charts):** 漲 body `--up`(紅) / 跌 body `--down`(綠) — 紅漲綠跌;
25	  crosshair `--crosshair` dashed, gridlines `--grid`. Volume subpane bars 紅漲綠跌 too.
26	- **MA overlays** = distinct categorical lines `--chart-1..6` (MA240 uses the 6th, `--chart-6`); toggle chips
27	  (pill 999px, active `--accent`). Legend chips in the ControlBar show each MA's color + value.
28	- **Subpanes** (KD · MACD · RSI · 布林) stack below, toggle chips; each uses `--chart-1..5` for its
29	  lines (never `--up`/`--down` — these are categorical indicators, not signed price).
30	- **Structure markers** — 支撐/壓力 as `--text-muted` dashed h-lines + label; N波 / K線型態 as small
31	  `--accent`-hairline annotation pins with 描述 tooltip (+1看多/−1看空 as label text, not color-alone).
32	- **ControlBar** — 還原股價 toggle · MA/indicator chips · `[日|週|月]` + `1M 3M 6M 1Y YTD 5Y` range
33	  pills (active `--accent`) · `⤓` CSV (Premium). **Timeframe drives one refetch**, persisted in URL.
34	- **Datasheet (展開歷史 ▾):** `日期·開·高·低·收·漲跌%·量(張)`, sticky thead, tabular-nums, 漲跌% cell
35	  `--up`/`--down`+▲▼; crosshair ↔ row sync (←/→ chart, ↑/↓ sheet, one `activeIndex`); active row
36	  `--surface-2` `aria-current`. Reduced-motion → crosshair snaps.
37	- **States** — loading = shaped skeleton (candle block + ghost rows), never spinner. `<Caveat
38	  kind="non-trading">` footer + 單位 + `DataFreshnessBadge`. All public compute (no mosaic here).

40	## Governance
41	A KD golden cross / bullish engulfing is a **描述 of the chart** ("KD 低檔黃金交叉"), **never "buy"**
42	(§7 non-trading). Pattern +1/−1 = observation label, not a position instruction. Non-trading `<Caveat>` footer.
